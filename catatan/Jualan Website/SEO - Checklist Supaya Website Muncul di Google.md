# SEO: Checklist Supaya Website Muncul di Google *(IG)*

> *"I created my website using AI, but it's not showing up on Google."*
> Kesalahan umum: website sudah jadi, tapi langkah-langkah di bawah tidak dikerjakan.

Kaitan: [[00 Jualan Website (MOC)]] · [[Keamanan - Checklist Sebelum Launch]] · Marketing Skills (SEO) di [[30 Plugin Claude Terbaik per Peran]]

## 5 hal dari video
| # | Langkah | Penjelasan singkat |
|---|---|---|
| 1 | **Daftarkan ke Google Search Console** | verifikasi kepemilikan domain supaya Google tahu website ada; pantau indeks dan error |
| 2 | **Kirim XML sitemap** | file `sitemap.xml` berisi daftar halaman, dikirim lewat Search Console |
| 3 | **Optimasi SEO & GEO** | SEO = mesin pencari biasa; **GEO (Generative Engine Optimization)** = supaya website juga dikutip AI seperti ChatGPT, Perplexity, dan Google AI Overview |
| 4 | **Meta title & description** | judul (± 50–60 karakter) dan deskripsi (± 150–160 karakter) unik di tiap halaman |
| 5 | **Google Business Profile** | profil bisnis di Google Maps & Search (alamat, jam buka, foto, ulasan). **Paling penting untuk UMKM lokal** |

## Tambahan teknis (minta Claude kerjakan)
- `robots.txt` yang tidak memblokir Google
- Struktur heading rapi (satu H1 per halaman), alt text di gambar
- **Schema / structured data** (`LocalBusiness`: nama, alamat, telepon, jam buka)
- Open Graph (tampilan saat link dibagikan di WA/IG/Facebook)
- Kecepatan & mobile-friendly (cek dengan Lighthouse / PageSpeed Insights)
- URL rapi, halaman kontak dengan alamat dan nomor yang sama persis dengan Google Business Profile
- Untuk GEO: konten jelas dan faktual, ada halaman FAQ, informasi bisnis lengkap

**Prompt untuk Claude sebelum launch:**
```
Audit website ini untuk SEO dan GEO sebelum launch. Pastikan:
1. Tiap halaman punya meta title (≤ 60 karakter) dan meta description (≤ 160 karakter) yang unik
2. Ada sitemap.xml dan robots.txt yang benar
3. Struktur heading rapi (1 H1 per halaman), semua gambar punya alt text
4. Ada structured data LocalBusiness (nama, alamat, telepon, jam buka) untuk bisnis: [DATA BISNIS]
5. Ada Open Graph tags untuk berbagi di WhatsApp/sosmed
6. Skor Lighthouse SEO & Performance ≥ 90 di mobile
7. Konten jelas untuk dikutip AI (FAQ, info bisnis lengkap)
Laporkan yang kurang beserta perbaikannya. Jangan ubah kode sebelum saya setujui.
```

## Peluang untuk jualan website
- Jadikan **"Setup SEO dasar + Google Search Console + Google Business Profile"** bagian dari paket. Banyak penjual website melewatkannya, jadi ini pembeda.
- Bisa juga jadi **jasa terpisah** untuk pemilik website yang tidak muncul di Google, atau upsell bulanan (laporan SEO, update konten).
