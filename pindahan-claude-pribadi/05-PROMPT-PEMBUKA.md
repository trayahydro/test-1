# Prompt Pembuka untuk Claude Code Pribadi

Salin seluruh teks di dalam kotak di bawah, lalu tempel sebagai pesan pertama di Claude Code
(setelah membuka folder proyek ini).

```
Halo Claude. Ini proyek pindahan dari sesi Claude Code saya sebelumnya. Tolong lakukan ini dulu sebelum
mengerjakan apa pun:

1. Baca CLAUDE.md di root folder ini.
2. Baca semua file di folder pindahan-claude-pribadi/ (01 sampai 05).
3. Baca catatan Obsidian di folder catatan/ (mulai dari dua file MOC: "00 Jualan Website (MOC).md"
   dan "00 Simpanan Tools AI (MOC).md").
4. Simpan ringkasan penting ke memori proyek kamu (CLAUDE.md boleh kamu lengkapi), termasuk aturan tetap,
   gaya komunikasi saya, status tiap proyek, dan langkah berikutnya.
5. Vault Obsidian saya di PC ada di: <ISI PATH VAULT OBSIDIAN ANDA, misalnya D:\Obsidian\Vault-Saya>.
   Salin folder catatan/Jualan Website dan catatan/Simpanan Tools AI ke vault itu (jangan menimpa catatan
   saya yang sudah ada; kalau namanya sama, tanya dulu). Mulai sekarang setiap catatan baru disimpan
   ke vault itu juga.
6. Cek apakah setup sudah jalan: Python venv (.venv), node_modules di video/, Playwright Chromium, FFmpeg.
   Kalau belum, jalankan skrip di pindahan-claude-pribadi/setup/ sesuai sistem operasi saya.
7. Bantu saya memasang plugin & MCP sesuai pindahan-claude-pribadi/04-MCP-SKILL-PLUGIN.md
   (yang bagian A dan B dulu; bagian C pilih paket awal jualan website saja), jelaskan tiap langkah
   dengan bahasa awam.

Setelah selesai, laporkan singkat: apa yang sudah kamu pahami tentang saya dan proyek-proyek saya,
status setup, dan 3 pilihan langkah berikutnya (misalnya: lanjut pelajaran 2 Frontend, buat proposal
untuk klien Teteh, atau revisi video SWRO). Gunakan bahasa Indonesia yang sederhana.
```
